# TS 系列报告骨架

**照这个填空就是最终报告。** `{…}` 是占位符，**其余每一个字逐字照抄，不许改**——
包括标点、加粗、`>` 引用块、表头与分隔行、图注与表题的位置。

报告按**论文实验章节**写：每一节都是「引导句 → 图表 → 小结」。
**图注在图下方、表题在表上方**（中文论文的排版惯例），图和表按在报告里出现的顺序
连续编号（`图 1`…`图 N`、`表 1`…`表 N`）。

三份骨架：单模型（默认）、有对比对象（单基准）、有对比对象（多模型）。
二 / 三 / 四 / 五这四节**三个分支完全一样**，差别只在第六节和后面的章节号。

> 骨架由 `tests/unit/visualization/test_ts_report.py` 守着，两条独立的检查：
> 1. **逐字扫描**——骨架里所有不含占位符的行（导语、表头、分隔行、口径说明…）
>    都必须在真报告里逐字出现、且顺序一致，章节标题序列也逐项比对；
> 2. **编号契约**——图注与表题整行都含 `{…}`，逐字扫描抓不到它们，
>    所以另外钉住：`图 N：` / `表 N：` 必须正好是 `1..N`（不跳号不重号）、
>    每节都有 `**小结**`、每张产物图都在正文里出现过、每段小结里都有数字。

## 八、口径与注意事项

- **值缺失的含义**：TS 为 “—” 表示该等级没有有效配对或无事件，与“评分为 0”不同；
- **BIAS 不是平均误差**：它是频率偏差，>1 表示预报事件偏多，<1 表示偏少；
- **跨时效不要直接平均后比较模型**：正式对比应使用共同有效样本与固定验证口径；
- 结果来自统一长表（`scores.csv` / `categorical_wide.csv`），逐行可追溯到具体时效与阈值。
