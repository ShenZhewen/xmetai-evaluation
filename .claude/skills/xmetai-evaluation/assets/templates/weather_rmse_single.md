# 确定性单成员多模型报告骨架

覆盖 `weather_rmse_<模型>_single` 批量跑出来的批次归档（`--summarize-det` 口径）。
同一 config 家族还有两份：[`weather_rmse_ens.md`](./weather_rmse_ens.md)（集合口径）与
[`weather_rmse_wave.md`](./weather_rmse_wave.md)（纬向 FFT + 球谐带功率谱补充分析）——
章节写法一致，差别在指标族。

**照这个填空就是最终报告。** `{…}` 是占位符，**其余每一个字逐字照抄，不许改**——
包括标点、加粗、`>` 引用块、表头与分隔行、图注的位置。

与 `weather_ts_single.md` 的差别：这一份**不按论文实验章节编号图与表**，
而是沿用被模板化的那份原报告的写法——章节用 `# 1.`…`# 11.`，
每张表由它上方的粗体小标题引导（**表不编号**），只有附录的四张图带 `图 N：` 图注。
这样做是因为报告里有多处**条件章节**（异常检出、变量覆盖缺口），
一旦表参与全局编号，条件章节一消失后面全要重排。

**编号契约**：`图 N：` 必须是 `1..4` 连续；每张图必须在正文里出现过。

> **本骨架目前没有测试守着**（`tests/` 在这个仓库里是空的，见 `README.md`
> 的「怎么被保证」）。按同一套格式写、能被 `assert_matches_skeleton` 直接认，
> 但**没有**对应的 `test_weather_rmse_single.py`；改 `det_report.py` 的渲染时得自己回来
> 对一遍骨架，别指望 CI 红给你看。
> **占位符不要跨行写**——`{` 和 `}` 两边都算占位符标记。
