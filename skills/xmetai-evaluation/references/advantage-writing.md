# 摘要优势段写作规则

每份报告第 1 节，在带数值的结论段之后、业务定性之前，写一段
`**相对优势**：…`。这段是给评审人读的**要素 × 能力**表述：要素落到具体
变量族，能力落到具体指标的可读名；不带数字、不带指标缩写、不带引用标记。
它只作用于摘要优势段，**正文其他章节照旧使用指标名与数值**。

这段可以整段搬进学术本子的「前期基础 / 相对优势」一节，所以语气按论文写，
不按宣传写。写法参照中国气象局《人工智能预报模型手册》的“性能 → 优势 →
特点 → 应用”结构：**数字归性能段，判断归优势段，方法归特点段**。

## 一、性能段与优势段的分工

手册里的数字几乎都在“性能”，优势段只给判断、地位、对手；少数才带一个数
（如“120 小时内台风路径明显优于 ECMWF”）。我们照这个分工：

- **数值结论段**（摘要第二段）承担数字、指标名与排名；
- **优势段**不复述数字、不出现指标缩写，只写“在哪个要素上、哪种能力、
  处于什么位置、意味着什么”；
- **方法/价值**各最多一句，放在优势段末尾，作为“为什么能赢”和“有什么用”
  的补充，不单独成段。

这样优势段可以整段搬进本子，而不与正文表格打架。

## 二、核心写法：要素 × 能力

### 2.1 最小骨架

一句话 = **要素族 + 能力 + 相对位置 + 学术含义**，四件事缺一不可。
要素说“在哪”，能力说“看什么”，位置说“多好”，含义说“意味着什么”。

- 要素族：风场、温度、水汽、气压、位势高度、降水、台风路径、台风强度……
- 能力：预测精准度、大尺度结构一致性、活跃度、强降水命中能力……
- 相对位置：领先 / 并列领先 / 与领先者基本持平 / 最接近。
- 学术含义：这个位置说明模型在什么意义上更接近实况。

四件事的顺序不要倒：先要素、再能力、再位置、最后含义。不要写成
“本模型很准，尤其在风场上”——那是先下结论、后补要素，评审读起来像宣传。

### 2.2 三种长度

同一条骨架可以写成三种长度，按本段要放几句来选：

- **短句**（只到位置）：在近地面与低层风场（u、v）上，本模型的预测精准度
  居首位。
- **标准句**（加含义）：在近地面与低层风场（u、v）上，本模型的预测精准度
  居首位，说明对风场基本形态与量级的把握更接近实况。
- **完整句**（加方法与价值）：在近地面与低层风场（u、v）上，本模型的预测
  精准度居首位；这一优势来自物理约束与集合扰动的协同，使风场的基本形态
  与演变过程都能保持稳定；可为台风路径与强对流天气研判提供参考。

短句适合与另一句并列；标准句是默认形态；完整句只在方法有依据、价值在
报告应用场景里时用。**方法句与价值句不能替代结果句**——先有位置，再谈
为什么、有什么用。

| 要素族 | 首选能力 | 可加的第二能力 | 不要配 |

### 2.4 五类句式与骨架的关系

第五节列的五类句式，都是这条骨架在不同“位置”上的说法：地位型把位置写成
“全球首个 / 第一梯队”，对比型写成“优于某模型”，能力型写成“具备……能力”，
效率型写成“分钟级 / 单卡”，方法型补“为什么能赢”。**骨架不变，只换位置
的说法**；不要把五类句式当成五套独立模板。

段落骨架见第十节：主赢点型、单族 + 局部型、结果 + 方法 + 价值型、
无主赢点型。

### 2.5 三条禁忌

1. 先下结论后补要素：“本模型很准，尤其在风场上”。
2. 只写能力不写要素：“预测精准度领先”——领先在哪？
3. 用“多要素”“整体”概括一个变量或一个量级。

规则：

1. **只用本批实际出现的要素**，不要从这张表里挑没评的变量。
2. 一族里列 2–4 个代表变量，用「等」收尾；不逐一罗列全部变量。

## 四、能力词典

左边是报告里的指标，右边是摘要里允许的能力名。**摘要不出现缩写**
（RMSE / ACC / TS / CRPS / FA / POD / FAR / BIAS / MAE / IQR 都不写）。

| 能力（摘要里写） | 对应指标（正文用） | 能配哪些要素 | 学术含义 |
| --- | --- | --- | --- |
| 预测精准度 | RMSE、综合相对 RMSE | 全部连续场要素 | 与实况的偏差大小 |
| 大尺度结构一致性 | ACC（距平相关） | **仅本批配置了 ACC 的要素**（常见 `z500`、`msl`） | 距平场空间相关 |
| 活跃度 / 强度幅度真实性 | FA、`activity_ratio` | **仅本批配置了 FA 的要素**（常见 `z500`、`u*`、`v*`） | 距平幅度是否接近实况 |
| 概率预报可靠性 | CRPS | 集合产品 | 概率评分 |
| 成员分散匹配 | Spread / RMSE | 集合产品 | 离散度校准 |
| 大尺度能量结构 | 纬向功率谱、球谐带功率 | 谱变量 | 尺度分布真实性 |
| 强降水命中能力 | TS | 降水 | 分类检验 |
| 命中率 / 漏报控制 | POD、漏报率 | 降水 | |
| 空报控制 | FAR | 降水 | |
| 降水事件频率 | BIAS（频率偏差） | 降水 | 不是平均误差 |
| 跨时效稳定性 | 分 lead 的 IQR、名次翻转 | 有分 lead 曲线的要素 | 是否只靠少数时效拉平均 |
| 台风路径偏差 | 路径误差（沿轨/横轨） | 台风 | |
| 台风强度偏差 | 强度 MAE | 台风 | |

**配对铁律**：只写本批实际算过的 `(要素, 能力)` 组合，以报告 §3 的指标口径表
与 §4 的分要素表为准。`rmse-batch-evaluation.md` 里那张变量 × 指标矩阵只是
某一份配置的示例，**批与批的 `VAR_METRICS` 不一样，不要照抄**。

常见的越界写法：

- 本批 ACC 只算了 `z500`，却写「风场（u、v）的大尺度结构一致性」——错。
- 本批 FA 没配给 `q700` / `t850`，却写「水汽、温度要素的活跃度」——错。
- 本批只评了 `q700` 一个水汽要素，却写「水汽要素整体领先」——错。
- 本批没有概率评分，却写「概率预报可靠性」——错。

## 五、五类优势句式（照手册提炼）

手册的优势句基本落在五类里。每段挑 1–2 类，不要五类全上。

1. **地位型**：全球首个 / 国际首创 / 进入第一梯队 / 业务化运行。
   **只在报告或引用来源能证实时写**；证据不足时降为「较早实现」「自主研制」
   「已完成业务化验证」这类可核实的说法。不要凭空写「全球首个」「国际领先」。
2. **对比型**：整体优于 / 明显优于 / 与……基本持平。
   **只点名本批实际参与对比的模型**；「明显」只在配对检验通过时使用。
   外部基准（ECMWF IFS/EPS、AIFS-ENS 等）只有在报告明确包含或引用时才写，
   且正文必须能对上，不在优势段里写引用编号。
3. **能力型**：具备……能力 / 能够…… / 支持……。
   必须落到要素 × 能力，不能空喊「能力强」。
4. **效率型**：分钟级生成 / 单卡推理 / 算力省。
   **只在报告记录了耗时或资源时写**；没有实测就删，不要拿别人的数字。
5. **方法型**：为什么能赢——物理约束、双源扰动、端到端同化、架构解耦。
   **只在报告、配置或方法说明里有依据时写**；不把别人的方法安到自己头上，
   也不把方法名当结论（「用了双源扰动」不等于「所以更好」）。

### 可点名对手与第三方评价

- **对手**：只写本批实际对比过的模型名；外部基准要有报告内的对比或引用，
  不能凭印象拉一个对手来比。
- **第三方评价**：示范计划排名、竞赛成绩、独立评估结论，只有报告收录了才写；
  写法用「在第三方示范评估中位列第一梯队」这类定性表述，不写具体名次与分数。
- 没有第三方材料时，不写「国际领先」「业内第一」这类无法核实的地位判断。

## 六、零数字规则

优势段里**一个数字都不出现**，包括：

- 指标数值、差值、百分比；
- 阈值（`≥25mm` 写「强降水」或「暴雨量级」）；
- 计数（「所评的多类要素」，不写「10 个变量」）；
- 层结数字（`500`、`850`、`10m` 都不写，改用中文层次）；
- 时效数字（`24h`、`120h` 写「短期 / 中期 / 延伸期」）；
- 变量代码里的数字（`u10m` 写 `u`，`z500` 写 `z`）；
- 引用编号（不写「见 §4.2」；按本规则，优势段不加引用）。

效率型与方法型句子也遵守这条：写「单卡即可完成推理」，不写「280 秒」；
写「分钟级生成」，不写「3 分钟」。

## 七、相对位置只有四档

1. **领先**：在全部对比模型中排名第一。
2. **并列领先**：与第一名落在并列区间（配对检验不显著，或差值低于报告
   现有的并列门槛，如暴雨的 0.005）。
3. **与领先者基本持平**：排名第二，但差距在噪声内。
4. **最接近**：不是第一，也不是并列，但在其余模型中离领先者最近。

不用「碾压、完胜、遥遥领先、全面领先」；「显著」只在配对检验通过时使用。
不写绝对分级（「达到业务可用」「合格线」），沿用硬性规则第 9 条。

## 八、四级取料（总是写满）

按顺序找，能找到哪一级就写哪一级；**每份报告都要有这一段**。

1. **主赢点**：在多个要素族或多个能力上排名第一 → 写「领先」。
2. **局部赢点**：总榜没有第一，但在某个要素族或某个能力上第一 →
   写「在 X 上领先」。
3. **并列 / 最接近**：没有第一 → 写「并列领先」或「与领先者基本持平」。
4. **全面落后**：以上都没有 → 仍写满一段，但写「相对最接近的是 X，
   差距集中在 Y」，**不把落后包装成优势**。

第四级是唯一不称「优势」的形态；它保证摘要结构完整，同时不违背
「不编造结论」。

## 九、句子规则

1. 一句一个要素族 + 一个能力；跨句可以换族、换能力，但同一句不堆四五个要素。
2. 一段 2–4 句、不分点；两个优势必须来自不同证据族（精度 / 结构 / 幅度 /
   稳定性 / 概率可靠性 / 强降水 / 个例 / 台风路径强度）。
3. **同源指标合成一句，不拆成两条优势**。预测精准度与大尺度结构一致性
   可以并列说，但不能把同一个场的误差与相关算成「两项独立优势」来凑数。
4. 只写本批实际算过的 `(要素, 能力)` 组合；每个组合必须能在第 4 章的分要素
   表里找到对应行（不把引用写出来）。
5. 不把局部赢说成整体赢：只赢一个量级、一个时效、一个过程，就限定在那个范围。
6. 不把个例说成整体能力：写某场暴雨就带「个例观察，不作整体推广」。
7. 学术动词优先：再现、刻画、捕捉、保持一致、误差更低、演变更稳；
   不用「好、强、牛、给力」。
8. **方法句/价值句各最多一句，且必须跟在一句结果句之后**；不写「只有方法、
   没有结果」的句式，也不写报告应用场景里没有的价值。
9. **地位型判断必须可核实**；「全球首个」「国际领先」没有依据就不写。

## 十、段落骨架

- **主赢点型**：在【要素族 A】上，本模型的【能力 A】居首位；在【要素族 B】上，
  【能力 B】同样领先，说明【学术含义】。
- **单族 + 局部型**：本模型的优势集中在【要素族】的【能力】：【学术含义】；
  在【局部范围，如强降水 / 中期 / 某过程】上，这一优势同样成立。
- **结果 + 方法 + 价值型**：在【要素族】上，本模型的【能力】居首位；
  这一优势来自【方法/架构，需有依据】，使【学术含义】；
  可为【报告里有的应用场景】提供参考。
- **无主赢点型**：本批没有出现整体领先，但在【要素族】的【能力】上与领先者
  基本持平 / 最接近；相对最弱的是【要素族】的【能力】。

## 十一、分报告类型的候选要素与能力

- **连续场**：要素取风场、温度、水汽、气压、位势高度中本批实际评过的族；
  能力取预测精准度、大尺度结构一致性、活跃度、跨时效稳定性、大尺度能量结构；
  集合再加概率预报可靠性与成员分散匹配。
- **降水**：要素是降水；能力取强降水命中能力、命中率 / 漏报控制、空报控制、
  降水事件频率、跨时效稳定性。
- **暴雨个例**：要素是极端降雨过程的核心雨带；能力取过程捕捉、同一根起报
  报到底时的中期持续性、量级层次、跨过程稳定性。
- **台风**：要素是台风路径、台风强度；能力取路径偏差、强度偏差、系统性偏移、
  逐台风一致性。

## 十二、示例

以下示例只示写法，实际以本批排名为准；每句对应的 `(要素, 能力)` 必须在本批
真的算过。

- **连续场**：在近地面与低层风场（u、v）、温度（t）、水汽（q）、气压（msl）
  与位势高度（z）等要素上，本模型的预测精准度均居首位；在位势高度（z）上，
  大尺度结构一致性同样最高，说明对环流形势的空间形态与演变过程的再现更稳定。
- **集合**：在概率预报可靠性上，本模型的综合评分更稳，成员分散与误差的匹配
  更合理；在所评的风场与位势高度要素上，活跃度与强度幅度更接近实况。
- **降水**：在降水要素上，本模型的强降水命中能力更稳，空报与漏报更均衡，
  说明对暴雨事件的捕捉更可靠；在较长预报时效上，这一优势没有明显衰减。
- **暴雨个例**：在极端降雨过程中，本模型对核心雨带的量级与位置把握更稳；
  同一根起报报到底时，中期逐日表现仍然稳定；这属于个例观察，不作整体推广。
- **台风**：在台风路径上，本模型主要时效的路径偏差更小，逐台风看多数个例
  保持领先，说明不是由个别个例拉平均；强度偏差也更接近实况。
- **结果 + 方法 + 价值**：在近地面与低层风场（u、v）上，本模型的预测精准度
  居首位；这一优势来自物理约束与集合扰动的协同，使风场的基本形态与演变
  过程都能保持稳定；可为台风路径与强对流天气研判提供参考。
