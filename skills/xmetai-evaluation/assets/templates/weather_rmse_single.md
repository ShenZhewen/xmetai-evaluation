# 确定性单成员多模型报告骨架

覆盖 `weather_rmse_single_<模型>` 跑出来的**评估产物目录**（`scores.csv` +
`manifest.json` + `diagnostics/`），由 `scripts/generate_det_report.py` 一次喂 N 份
（≥2）出多模型对比报告。
同一家族还有两份：[`weather_rmse_ens.md`](./weather_rmse_ens.md)（集合口径）与
[`weather_rmse_wave.md`](./weather_rmse_wave.md)（纬向 FFT + 球谐带功率谱补充分析）——
章节写法一致，差别在指标族。

**照这个填空就是最终报告。** `{…}` 是占位符，**其余每一个字逐字照抄，不许改**——
包括标点、加粗、`>` 引用块、表头与分隔行、图注的位置。

与 `weather_ts_single.md` 的差别：这一份**不按论文实验章节编号图与表**，
而是沿用被模板化的那份原报告的写法——章节用 `# 1.`…`# 11.`，
每张表由它上方的粗体小标题引导（**表不编号**），只有附录的图带 `图 N：` 图注。
这样做是因为报告里有多处**条件章节**（异常检出、变量覆盖缺口），
一旦表参与全局编号，条件章节一消失后面全要重排。

**编号契约**：分三个互不干扰的命名空间——

- 正文与必出附录用 `图 N：`，编号从 `1` 起、不重号、不跳号到用不到的号；
  其中 `图 1`–`图 4` 与 `图 7` 是**必出**（前者每个批次都有对应数据，后者是
  综合评分的雷达图，只要跑得出报告就画得出），`图 5`–`图 6` 按数据可得性出
  ——出不了的那一节**保留节位、写明「本批未出」及原因**，不指一张不存在的
  文件（所以出现「图 5 缺、图 6 在」是正常的，缺的是哪一节，那节的标题下面
  写着）；每张出得来的图必须在正文里出现过；
  `图 7` 排在可选段之后仍是**必出号**，所以它的缺失不是「本批未出」而是渲染器
  坏了——`图 5`、`图 6` 允许缺席，`图 7` 不允许；
- 分纬度带可选块用 `图 L1：`…`图 L2：`，块内从 1 连续；
- 分季节可选块**预留** `图 S1：`…`图 S2：`；这一块目前本批未出，所以现在不出图、
  号留空（见文末「附 S」）。

**可选块**：报告末尾两个块按需保留——`## 附 L 分纬度带结果（可选）` 与
`## 附 S 分季节结果（可选）`。整块删掉（连它的表、图注、`图 L*`/`图 S*` 一起删）
**不需要重排任何编号**，这就是给它俩单开命名空间的原因；要用就整块留着，
不要只删图不删表。

两块的数据都来自评测产物里**同一张长表**（`region` 列 + 起报时刻），
**不是**另跑一次评测，也不额外读别的文件。拿不到数据时**保留节位并标注
「本批未出」**，不静默省略、也不留空表——与 `weather_rmse_wave.md` 里
球谐带那三节同一套约定。

> **本骨架目前没有测试守着**（`tests/` 在这个仓库里是空的，见 `README.md`
> 的「怎么被保证」）。按同一套格式写、能被 `assert_matches_skeleton` 直接认，
> 但**没有**对应的 `test_weather_rmse_single.py`；改 `det_report.py` 的渲染时得自己回来
> 对一遍骨架，别指望 CI 红给你看。
> **占位符不要跨行写**——`{` 和 `}` 两边都算占位符标记。
> **`{报告日期}` 填报告的生成日期**（`YYYYMMDD` 八位，`det_report.report_date()`
> 就是它），**不是数据末日期**——数据覆盖到哪天，正文第 2 节已经写了
> 「覆盖 N 天（起，止）」，抬头这一格只承载「这份报告是什么时候出的」。
> 代价是产物**不再逐位可复现**：同一天跑两次一样，隔天跑就不同。

这一节把第 3 节那张总表的**综合评分**摆成多边形：每根轴一种能力，每个模型一个
多边形，**越靠外越好**。它不引入任何新算法，只是把总表的数换个读法——看的是
「能力形状」，不是「谁排第一」：两个模型综合分接近时，雷达图能显出差距集中在
哪几项上。

共 4 根轴，方向已在括号里标明（越高越好 / 越低越好）：综合相对RMSE（越低越好）；
ACC (%)（越高越好）；FA偏差 (pp)（越低越好）；频谱对数RMS（越低越好）。

**读法**：纵轴 0–1 是**批内相对分**，每根轴上 1 = 本批最好、0 = 本批最差
（各轴方向先行统一）。这是{模型数}个模型互比出来的相对位置，**不是绝对能力分**
——全批都差时每根轴照样有人拿 1。某一根轴上所有模型打平时，该轴一律画在满格
1.0（画成 0 会让多边形凭空凹进去），所以**满格不代表领先**，要回正文看绝对数值。

## 附 S 分季节结果（可选）

**本块本批未出。** 产物长表里没有季节维度（只有 `init_time`），季节要现推；

两条口径 2026-09-22 已定，照做即可（完整工序见
`references/rmse-batch-evaluation.md` §6「按需子集对比」）：

- 季节按**起报时刻**（`init_time`）切，**不按** `valid_time`——报告整套契约建立在
